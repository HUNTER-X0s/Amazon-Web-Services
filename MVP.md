What is a Minimum Viable Product?

* Definition: The simplest version of a new product that has just enough core features to solve a user's problem.
* Purpose: Companies use an MVP to test market demand and gather real user feedback before spending time and money on full development.
* Origin: The concept became popular through the Agile Alliance and the Lean Startup methodology.



* Engineering: Minimum Viable Platform (a foundational platform setup used to test and scale internal developer tools







Model-View-Controller (MVC)

* It is a software design pattern that divides an application into three interconnected parts to separate business logic from the user interface.
* The Three Components Model: Manages the application's data, business logic, rules, and database interactions.
* View: Handles the presentation layer and displays the user interface to users.
* Controller: Acts as the intermediary that receives user input, talks to the model, and selects the view to render.



How It Works:

* A user interacts with the View (like clicking a button or entering a URL).
* The Controller receives this request and asks the Model for data or to update state.
* The Model processes the data and returns it to the Controller.
* The Controller sends the data to the View, which updates the screen for the user.





Benefits of MVC:

* Separation of Concerns: Keeps data logic, user interface, and routing distinct and clean.
* Maintainability: Makes code easier to update, scale, and debug without breaking other parts.
* Testability: Allows developers to test models, views, and controllers independently.
* Team Collaboration: Enables multiple developers to work simultaneously on different components.
